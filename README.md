# WebMitra

A modern agency website showcasing web design, UI/UX design, and digital solutions for startups and small businesses.

![Preview](assets/preview.png)

---

## Overview

WebMitra is a portfolio agency website built to present digital design and development services in a clean, modern, and conversion-focused way.

The project demonstrates responsive layouts, strong visual hierarchy, and service-oriented UX.

---

## Features

- Responsive Landing Page
- Agency Branding
- Service Showcase
- Portfolio Section
- Contact CTA
- Mobile Friendly Design
- Modern UI Components
- Clean Navigation
- Smooth Scrolling

---

## Design Goals

- Establish brand credibility
- Generate client inquiries
- Showcase digital services
- Present previous work
- Encourage conversions
